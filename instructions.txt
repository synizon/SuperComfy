SUPERCOMFY — QUICK INSTRUCTIONS
===============================

1. INSTALL
   ./install.sh
   Installs Python 3.13, PyTorch for your CUDA version (13.0-13.3 supported,
   12.6+ works), and the latest ComfyUI release into comfy/.
   Tip: ./install.sh --dry-run shows what would happen without installing.

2. RUN
   ./run.sh
   Pick a speed preset (1=pytorch default, 2=comfy-kitchen fastest).
   Open the printed URL: http://127.0.0.1:8188 locally,
   or the https://...proxy.runpod.net link on RunPod.
   Change the preset later: ./run.sh --select
   Stop with Ctrl+C.

   run.sh also serves a web DASHBOARD on port 8080 (URL printed at start):
   open ComfyUI/JupyterLab, install nodes, download models, and import LoRAs
   (drag-and-drop, link, or zip) from the browser. Same password as ComfyUI.

3. UPDATE
   ./update.sh
   Moves ComfyUI to the newest release and refreshes its dependencies
   without breaking torch.

4. PASSWORD
   Edit .env and set:  COMFY_AUTH=yourpassword
   The web UI then asks for user "comfy" + that password. Required before
   exposing ComfyUI to the internet (RunPod does this automatically).

5. JUPYTERLAB (optional)
   Install once:  SUPERCOMFY_JUPYTER=1 ./install.sh
   Enable in .env: JUPYTER_ENABLE=1  (on RunPod it is on automatically)
   The access token is JUPYTER_TOKEN from .env, or printed at start.

6. CUSTOM NODES
   ./downloadnodes.sh          Pick popular nodes from a menu.
   ./downloadnodes.sh --all    Install the whole list (supercomfy/nodes.txt).
   Node dependencies are installed under pins so they can never break torch.

7. MODELS + LORAS
   ./downloadmodels.sh                Category menu (supercomfy/models.json).
   ./downloadmodels.sh --lora LINK    Import a LoRA from a HuggingFace link,
                                      a direct URL, or a local .zip/.safetensors.
   Set HF_TOKEN in .env for gated HuggingFace models.

8. SETTINGS
   All settings live in .env (created from .env.example). Ports, password,
   attention preset, extra ComfyUI flags — each variable is documented there.

9. RUNPOD
   Deploy the prebuilt image ghcr.io/synizon/supercomfy — no install step,
   ComfyUI self-updates at pod start. Template: 400GB container disk, 35GB
   volume at /persistent, HTTP ports 8080/8188/8888, env COMFY_AUTH (required)
   + JUPYTER_TOKEN, GPU filter "CUDA Version = 13.0".
   Full guide: docs/cookbooks/runpod.md

PROBLEMS?
- "not a CUDA build" -> re-run ./install.sh (a custom node replaced torch).
- "No NVIDIA CUDA detected" -> install/upgrade the NVIDIA driver (580+).
- Port in use -> another ComfyUI is running, or change COMFY_PORT in .env.
